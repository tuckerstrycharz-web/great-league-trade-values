# The Great League: Stock Exchange

Rest-of-season trade values for The Great League (ESPN, 12-team, full PPR, 1QB): a consensus of CBS, Roto Street Journal, FantasyCalc and ESPN projections, with a player board, trade builder, team portfolios and waiver wire.

Live: https://tuckerstrycharz-web.github.io/great-league-trade-values/

Static site, no server or accounts. Built from the private `nfl-fantasy-football` repo with `tools/build_site.py` and updated weekly.
